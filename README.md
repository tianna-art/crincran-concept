# crincran — Concept

> **夢の途中にある困難を、失敗作にしない。**
> 曲がってきた時間が、未来の自分を支える地図になる。

諦めきれない夢の途中で経験する困難・挫折・迷い・試行錯誤を記録し、時間をかけて自分の輪郭と可能性が見える  
「人生の地図」へ変えていくライフデザインブランド **crincran** の事業思想をまとめたリポジトリ。

## 🔗 Site

**https://tianna-art.github.io/crincran-concept/**

## About the name

crincran は、イギリスにある波状のレンガ壁 **Crinkle Crankle Wall** に由来する。  
まっすぐな壁は自立するために厚みを必要とするが、波状に曲がった壁は、その曲線自体が強度を生み出す。

> 曲がっていることが、弱さではなく、強さの理由になっている。

## Concept Graph

中心の `crincran` から5つの領域が伸び、そこから各概念のノードへ枝分かれする。

| 領域 | 内容 |
|---|---|
| **思想 / IDEA** | 波打つ壁・点を線にする・意味は後から・芯ではなく輪郭・自己受容と向上心・憧れは可能性・困難の中に残るもの・外側の物語を借りる・自然という言語（川／根／地層／霧／季節／潮／新芽）・人間のプロセスを残す |
| **プロダクト / PRODUCT** | 入力したくなる言葉・表と裏を分ける・AIの役割・根拠を必ず添える・人生の地図・返すアウトプット・次の小さな実験 |
| **ユーザー / READER** | 夢を諦めきれない人・ターゲットの感情・失敗作だと思わなくなる・自分なりの判断軸・今の輪郭を受け取る・憧れという入口 |
| **ブランド / BRAND** | 機能だけでは成立しない（Record／Evidence／Interface／Philosophy／Process／Experience）・編集姿勢・Visual Direction・コンテンツの役割・ブランドコピー・しないこと |
| **事業 / BUSINESS** | 中心はアプリ・Art Bar・1,000人 × ¥500・現時点の仮説・判断基準・汎用AIとの差 |

**操作** — 点をクリックで展開／もう一度で収束、末端ノードで右パネルに本文と関連ノード、ドラッグで移動、ホイールで拡大、下部の凡例で領域をフォーカス、RESETで初期状態へ。

階層のつながりは実線、領域をまたぐ関連は点線で描かれる。全60ノード・36の関連リンク。各ノードから Vision の該当章へ移動できる。

## Thoughts のビュー

| View | 扱う論点 |
|---|---|
| **どう伝えるか** | ポジショニングを一言で伝えにくい／自己理解と憧れの接続／憧れを誰が体現するのか |
